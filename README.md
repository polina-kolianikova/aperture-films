# APERTURE

Independent interactive film studio concept by BlackStack Studio.

Serve this folder with any static HTTP server. No build step or backend.
Live: https://polina-kolianikova.github.io/aperture-films/

Features: reversible native-scroll aperture, photographic filmstrip, study filter, accessible image dialog and local project brief download.

Images and fonts are local. Their licenses are in assets. Briefs are downloaded locally; no form submission or enquiry service is connected.
